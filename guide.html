איך בונים אפליקציה כזאת בעצמך

הרעיון המרכזי פשוט: לוקחים דף אמיתי מהאינטרנט, שומרים אותו למחשב, ובונים עליו משלנו — בלי שרת ובלי מסד נתונים. כאן מוסבר שלב-אחר-שלב בדיוק איך הדוגמה הזו נבנתה, כדי שתוכלו ללמוד ולבנות דברים משלכם.

🎓 התוכן כאן הוא להמחשה ולימוד בלבד
1

הרעיון

במקום לכתוב עמוד מאפס, מתחילים מעמוד קיים באינטרנט שכבר נראה טוב, שומרים אותו, ואז משנים אותו שיעשה מה שאנחנו רוצים. ככה לומדים איך אתרים בנויים — ומקבלים תוצאה מהממת מהר.

הדרך: אתר קיים → שמירה למחשב → בנייה עצמית מעליו
2

שומרים את הדף מהאינטרנט

פותחים את הדף בדפדפן ולוחצים שמירה בשם… ובוחרים "עמוד אינטרנט, מלא" (Webpage, Complete). הדפדפן שומר קובץ .html אחד, וגם תיקיית _files שבתוכה כל העיצוב (CSS), התמונות והגופנים של הדף — בדיוק כמו שהם.

אחרי שמירה מקבלים קובץ HTML + תיקיית קבצים עם כל העיצוב

בראש קובץ שנשמר ככה הדפדפן אפילו מסמן מאיפה הגיע:

<!-- saved from url=(0060)https://example.com/page -->
3

בונים על זה בעצמנו

עכשיו פותחים את ה-.html השמור בכל עורך טקסט ומשנים אותו: שומרים על המראה היפה, מוחקים את החלקים שצריכים את השרת המקורי, ומוסיפים קוד משלנו. ככה הדף הופך מ"צילום" של אתר אחר למשהו חי שאנחנו שולטים בו.

צילומי מסך אמיתיים מתוך הדוגמה

4

מעבר בין מסכים בלי שרת

בלי מסד נתונים, איך מעבירים את הפרטים ממסך "היצירה" למסך "האישור"? משתמשים בזיכרון הקטן של הדפדפן עצמו — localStorage. שומרים שם את הפרטים, עוברים לדף הבא, ושם קוראים אותם חזרה.

// מסך היצירה — שומרים את הפרטים במכשיר
localStorage.setItem('pg_passData', JSON.stringify({
  student: name, klass: klass, reason: reason
}));
location.href = 'מערכת פגישונים דף 2.html';

// המסך הבא — קוראים אותם חזרה
var d = JSON.parse(localStorage.getItem('pg_passData'));
כל המידע נשאר רק במכשיר — שום דבר לא נשלח לאף שרת.
5

פעולה מיידית כמו באפליקציה אמיתית

כשלוחצים "נעל אישור", במקום לטעון דף חדש (שלוקח זמן) — פשוט משנים את המסך הנוכחי במקום: מחליפים את החותמת, הכיתוב והכפתור. אין טעינה, אין המתנה, מיידי.

function pgCommitExit(){
  var hh = now();                 // השעה עכשיו
  save(function(d){ d.exitTime = hh; });
  pgSetStatus('status-out', 'יצא מבית הספר');   // משנים במקום
  pgSetTile('שעת יציאה', hh);                     // בלי טעינת דף
}
6

הכול נשאר על המכשיר

אין מסד נתונים, אין חשבונות, אין סיסמאות. כל אישור "חי" רק בדפדפן של אותו מכשיר. זה פרטי לגמרי, עובד גם בלי אינטרנט, ואי אפשר "לרגל" על אף אחד — כי אין שרת שאוסף כלום.

פרטי · מקומי · עובד גם אופליין
7

הופכים לאפליקציה אמיתית

מוסיפים קובץ קטן בשם manifest.json ושורה-שתיים בכותרת הדף. אז בטלפון אפשר ללחוץ "הוסף למסך הבית", והאתר נפתח במסך מלא עם אייקון — בלי שורת הכתובת — בדיוק כמו אפליקציה שהורדתם מהחנות.

{ "name": "מערכת פגישונים",
  "display": "standalone",     // מסך מלא, בלי שורת כתובת
  "start_url": "./index.html",
  "theme_color": "#223e9c" }
